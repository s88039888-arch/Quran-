# تطبيق سكينة — مشروع Android

هذا المشروع يحوّل نسخة HTML إلى تطبيق Android باسم **سكينة**.

## التشغيل
1. افتح المجلد في Android Studio.
2. انتظر Gradle Sync.
3. اختر هاتف Android أو Emulator.
4. اضغط Run ▶.
5. لإنشاء APK: من Android Studio اختر **Build > Build APK(s)**.

## ما تم تضمينه
- تطبيق Android أصلي يحتوي WebView داخلي.
- ملف `index.html` داخل `app/src/main/assets/`.
- زر إعدادات داخل التطبيق لتغيير الخط، حجم الخط، حجم خط القرآن، والوضع الفاتح/الداكن.
- حفظ الإعدادات على الجهاز.
- صلاحية الإنترنت لتحميل بيانات المصحف عند أول تشغيل.
- اسم التطبيق: سكينة.
